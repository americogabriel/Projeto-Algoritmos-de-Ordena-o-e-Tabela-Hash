# Projeto de Estruturas de Dados II

Trabalho prático desenvolvido em grupo para a disciplina de **Estruturas de Dados II**. O repositório reúne implementações de algoritmos clássicos de ordenação e uma estrutura de busca baseada em Tabela Hash.

---

## 📌 Conteúdo do Repositório

### 1. Algoritmos de Ordenação
Um programa interativo que permite ao usuário escolher e executar diferentes algoritmos para ordenar conjuntos de dados:
* **Bubble Sort**
* **Selection Sort**
* **Merge Sort**
* **Quick Sort**

### 2. Tabela Hash
Módulo independente focado na implementação da estrutura de dados **Tabela Hash**, abordando conceitos de tratamento de colisões e funções de espalhamento (hash).
